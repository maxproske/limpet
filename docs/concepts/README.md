# Concepts

Short notes on concepts we've actually worked through, one file per concept (for example `file-descriptors.md` or `exit-status.md`). A note is written after a concept comes up in a lesson: you explain it first, then the note is corrected and tightened. These notes are for review and later reference, not a textbook.

Each note covers:

- **What it is**, in a few sentences.
- **The mental model**, with a diagram if it helps.
- **How we observed it**: the commands and experiments.
- **Where it shows up in limpet.**
- **Misconceptions**, especially ones you held at some point.
- **Sources**: man pages, Go docs, kernel docs.
